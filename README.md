# FrameBoost iOS

FrameBoost is an iOS video frame-rate enhancement app.

## Goals
- Import videos from Photos and Files
- Preview source video and output settings
- Convert video frame rate with a processing pipeline designed for future optical-flow interpolation
- Support 2x and 4x output modes
- Show progress and allow cancellation
- Export processed videos
- Build with GitHub Actions
